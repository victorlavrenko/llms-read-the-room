# Human-subjects context

The study was conducted independently, outside an institution with an applicable
human-subjects review board. It was a voluntary, minimal-risk public web study collecting
binary judgments, response times, and three coarse self-reported background variables.
Participants explicitly consented before starting. No account credentials or sensitive
demographic questionnaire were collected.

This public reproduction package uses deidentified records. Original nicknames, original session and
nominal-participant identifiers, exact timestamps, deployment identifiers, and per-session
background profiles are not included.
