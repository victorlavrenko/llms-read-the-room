# Release v1.1.0 — 17 September 2026

This update aligns the repository with the revised paper and adds the focused robustness diagnostics used in the final text.

Changes:

- reframed the paper around the central generation-vs-preference-knowledge paradox ("AI slop" versus strong audience judgment);
- preserved the human-vs-LLM judge comparison while treating retweet/repost prediction as a behavioral probe of narrative preference;
- added crossed session/item bootstrap intervals for matched contemporary human-model gaps;
- corrected the Tan et al. human-comparison description and included their held-out supervised classifier baseline;
- added the 100-pair prompt wording, X/Y reversal, and explicit-confidence robustness component with raw archived calls and a standard-library frozen-result verifier;
- retained the 85% practical text-only ceiling and 82–90% sensitivity envelope;
- updated the compiled paper PDF and reproducibility documentation.
